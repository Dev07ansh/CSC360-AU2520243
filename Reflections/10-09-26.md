## Notes

### Topic 1 - Data Streaming vs Downloading
- In downloading, the entire file is received first; in streaming, there is a continuous flow of data
- Streaming is used for real-time processing and large data sets where data can be infinite

### Topic 2 - Statistical Calculations
- Difference between **Population Mean** and **Sample Mean:** `n-1` is used in Sample Mean (Bessel's correction)
- **Variance** is calculated to understand the dispersion of data

### Topic 3 - Web Architecture and SEO
- **Server-side rendering (SSR):** better for SEO because search engine crawlers get full HTML
- **Client-side rendering (CSR):** dependent on JavaScript, which can sometimes cause crawling delays

### Topic 3 - Database Selection
- **Relational database:** suitable for structured data and complex relationships
- **Graph database (e.g., Neo4j):** more efficient for network-based data and complex joinings
