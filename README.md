This is CSC360 course Repository for **CSC360: Computer Graphics and Digital Image Processing — Monsoon 2026**, containing course notes, classwork, homework, programming exercises, and project implementations.

## Repository Structure

- `README.md` — project overview and repository information.
- `Code/` — contains implementation code and related Java project files.
  - `GraphicalSquare.java` — standalone graphical square implementation.
  - `square/` — Maven-based Java project for the square exercise.
    - `pom.xml` — Maven configuration and dependencies.
    - `src/main/java/com/csc360/` — main Java source code.
    - `src/test/java/com/csc360/` — unit tests for the project.
    - `target/` — compiled classes and generated build artifacts.
- `Reflections/` — reflection notes or learning summaries from class activities.
  - `session-1-.md` — reflection for session 1.
  - `Images/` — images and supporting visual files used in reflections or coursework.

This repository is organized to support the course workflow by keeping notes, code, experiments, and project files in separate sections for easier navigation and study.
